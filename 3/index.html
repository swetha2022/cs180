Introduction

In this project, I explored the use of projective transformations and image warping to create image mosaics. The process involved capturing photographs with projective relationships between them, computing homographies from point correspondences across each pair of images, performing inverse warping using nearest neighbor and bilinear interpolation, and blending the warped images into mosaics.

A.3: Warp the Images

I implemented image warping using homographies and explored two interpolation methods: nearest neighbor and bilinear interpolation. Nearest neighbor interpolation rounds mapped coordinates to the nearest pixel value, while bilinear interpolation uses a weighted average of the four neighboring pixels for smoother results. Below are results demonstrating image rectification and a comparison between the two interpolation methods. Nearest neighbor interpolation is faster but produces jagged edges and aliasing, whereas bilinear interpolation is slower but yields smoother, higher-quality warps.

A.4: Blend the Images into a Mosaic

Finally, I created mosaics from the photographs I took using homographies, interpolation, and alpha blending. I used alpha blending to minimize visible seams and “ghosting” artifacts. For each mosaic, one image was chosen as the reference, and the other image was transformed into its coordinate system using warping with bilinear interpolation. To accommodate both images in a single output, I first computed the bounding box of all corner points after transformation to determine the size of the final mosaic canvas. This ensured that both images fit entirely within the canvas. Once both images were placed onto the mosaic canvas, I generated alpha masks for each image using a distance-based approach: the mask was strongest (value 1) near the center of the image and fell off smoothly to 0 at the edges. These alpha masks were then used to perform weighted averaging at each pixel, blending overlapping regions according to their relative alpha values. Pixels near the center of an image contributed more heavily, while edge pixels were faded out to reduce visible seams. This procedure allowed both images to merge naturally on the canvas, producing a single coherent mosaic with smooth transitions and minimal artifacts.

B.1: Harris Corner Detection

I applied the Harris corner detector to identify strong interest points in the image and computed the corner response strengths to determine the top-scoring candidates. To refine this initial set, I implemented Adaptive Non-Maximal Suppression (ANMS), which computes a suppression radius for each point based on its distance to stronger corners. If a point is the strongest in its neighborhood, its radius is set to infinity. Finally, I selected the top 500 points (using c_robust = 0.9) with the largest radii, resulting in spatially well-distributed and robust corners across the image.

B.2: Feature Descriptor Extraction

I implemented feature descriptor extraction by sampling 8x8 axis-aligned patches around the detected corner points. To create smooth and robust descriptors, I first blurred the grayscale image using a Gaussian filter (sigma=1.0) and sampled each patch from a larger 40x40 window to capture broader context. After downsampling, each blurred crop was resized to 8x8 and bias/gain-normalized by subtracting the mean and dividing by the standard deviation. This normalization ensures that the resulting descriptors are illumination-invariant and consistent across different images.

B.3: Feature Matching

I implemented feature matching by comparing the extracted feature descriptors between two images. For each descriptor in the first image, I computed its squared Euclidean distance to all descriptors in the second image and identified the two nearest neighbors. Using Lowe's ratio test, I retained matches where the ratio between the first and second nearest neighbor distances was below a threshold of 0.7, effectively filtering out most inaccurate correspondences. The resulting matched feature pairs represent points that are visually similar and likely correspond to the same physical locations across both images.

B.4: RANSAC for Robust Homography

Finally, I implemented 4-point RANSAC to robustly estimate the homography between two images. In each iteration, four random correspondences were sampled to compute a candidate homography, which was then used to project points from the second image onto the first. Reprojection errors were measured for all correspondences, and points with errors below a tolerance of 1 pixel were considered inliers. The homography with the largest number of inliers was selected as the best model, and a final homography matrix was recomputed using all inliers from this set. This approach effectively rejects outliers from incorrect matches, leading to accurate alignment and seamless automatic image mosaics.

Introduction

In this project, I explored diffusion models. I worked with pre-trained diffusion models to understand the denoising process and perform fun image generation experiments. I began by experimenting with DeepFloyd IF, a state-of-the-art text-to-image model, to generate images from text prompts and perform various manipulations. I implemented forward and reverse diffusion processes, learning how noise is progressively added and removed. I then explored techniques like Classifier-Free Guidance (CFG) to improve image quality and image-to-image translation to transform existing images.

Part 1.1: Implementing the Forward Process

The forward diffusion process gradually adds Gaussian noise to an image over a series of timesteps. I implemented this by using the closed-form solution that allows us to directly compute a noisy image at any timestep t without iterating through all previous steps. The formula uses pre-computed noise schedule coefficients to blend the original image with random noise. I tested this on the "Campanile" test image provided, creating noisy versions at timesteps t = [250, 500, 750]. As expected, the image becomes progressively noisier at higher timesteps, eventually becoming almost pure noise.

Part 1.2: Classical Denoising

To understand the challenge of denoising, I applied Gaussian blur filtering to the noisy images from Part 1.1. While Gaussian blur can remove some noise, it also significantly reduces image sharpness and detail. The results show that classical denoising methods are insufficient for heavily noised images, motivating the need for learned diffusion models that can intelligently reconstruct image structure.

Part 1.3: One-Step Denoising

Next, I used the pretrained diffusion model's UNet to estimate the noise in the noisy images and attempted single-step denoising. The UNet predicts the noise component at each timestep, which can then be removed to recover a cleaner image. However, one-step denoising from heavily corrupted images (high timesteps) produces blurry, low-quality results because the model needs multiple refinement steps to progressively recover fine details. The results are better than Gaussian blur but still far from the original image quality.

Part 1.4: Iterative Denoising

To achieve high-quality reconstruction, I implemented the iterative denoising procedure. Starting from a noisy image, the algorithm repeatedly estimates and removes noise, gradually refining the image over multiple timesteps. I used a strided timestep sequence (every 30 steps from 990 down to 0) to efficiently denoise while maintaining quality. The results show dramatic improvement compared to one-step denoising, successfully recovering the original Campanile image from pure noise. I also visualized intermediate denoising steps at timesteps [690, 540, 390, 240, 90] to show the progressive refinement.

Part 1.5: Diffusion Model Sampling

With the iterative denoising procedure working, I could now generate completely new images from pure random noise. Starting from Gaussian noise, the model progressively denoises to create images matching the conditioning prompt. I generated five images using the prompt "a high quality photo" and visualized the denoising trajectory for one of them. The results demonstrate the model's ability to synthesize diverse, realistic images from scratch.

Part 1.6: Classifier-Free Guidance (CFG)

To improve image quality and adherence to text prompts, I implemented Classifier-Free Guidance. CFG works by combining conditional and unconditional noise predictions, extrapolating in the direction of the conditional prediction. The guidance scale parameter controls this effect: higher values produce images that match the prompt more closely but may sacrifice diversity. I experimented with guidance scales of [1, 5, 7, 10] for the prompt "a high quality photo". Results show that moderate guidance (around 7) provides the best balance of quality and coherence.

Part 1.7: Image-to-Image Translation

I implemented image-to-image translation by starting the denoising process from a noisy version of an existing image rather than pure noise. The i_start parameter controls how much noise is added initially—smaller values preserve more of the original structure, while larger values allow more creative freedom. I tested this with the Campanile image and various prompts, using different i_start values of [1, 3, 5, 7, 10, 20]. The results show how the balance between faithfulness to the original and adherence to the new prompt changes with noise level.
